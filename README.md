# Pabasara Gems

Simple GitHub Pages gemstone website sample.

## Upload to GitHub
Upload these items to the root of your `gems` repository:

- `index.html`
- `styles.css`
- `script.js`
- `images/` folder

Then open **Settings → Pages** and use:

- Source: `Deploy from a branch`
- Branch: `main`
- Folder: `/(root)`

Your project URL should be:

`https://cpox123.github.io/gems/`

## Images
The gemstone and jewellery images in this sample were generated for the demo. Replace them with real Pabasara Gems product photos before using the site as a real product catalogue.
