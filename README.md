# Pabasara Gems - Sample Website

This is a simple one-page gemstone selling website sample made for GitHub Pages.

## What is included
- Sinhala navigation and content
- Dark navy + gold gem shop style
- Color filters
- Gem type filter
- Cut filter
- Sample price filter
- Product cards
- Jewellery / ring inspiration gallery
- Mobile responsive layout
- Demo inquiry form

## Important
- All prices and gemstone data are demo placeholders.
- The sample uses remote Pexels images. Replace them with your own real gemstone photos before publishing the final shop.
- Replace the sample phone number, WhatsApp number, email, location and social links.

## Upload to GitHub Pages
1. Put `index.html` in the root of your GitHub repository.
2. Go to GitHub repository Settings > Pages.
3. Choose the branch used for Pages, usually `main`, and the root folder.
4. Save and wait for GitHub Pages to publish.

## WhatsApp button later
The current inquiry buttons only scroll to the contact form. They can be changed to open your WhatsApp chat when you provide the real WhatsApp number.
