# Pabasara Gems

Simple GitHub Pages sample inspired by the clean structure of the Sandu Cakes site.

## Main files
- `index.html` - page structure
- `styles.css` - design
- `script.js` - simple colour filter and enquiry demo
- `content/gems/index.json` - gem catalogue data
- `admin/` - reserved for a future CMS/admin setup
- `images/gems/` - folder ready for your own gem photos

## GitHub Pages
Upload the **contents of this folder** to the root of your `gems` repository. Make sure `index.html` is directly in the repository root.

The expected Pages URL is:
`https://cpox123.github.io/gems/`
